## Installation

1. Install a userscript manager — [Tampermonkey](https://www.tampermonkey.net/) (recommended) or [Violentmonkey](https://violentmonkey.github.io/).
2. Click **New Script** in the extension, then delete the placeholder and paste in the contents of [`discogs-juno-search.user.js`](./discogs-juno-search.user.js).
3. Save (`Ctrl/Cmd + S`). If prompted, accept the cross-origin permission request for `juno.co.uk`.
4. Visit any Discogs marketplace, release, or master page — you should see a ▶ play button next to release titles.
